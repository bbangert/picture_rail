# Fonts

| File | Family | Licence |
|---|---|---|
| `Antonio-Regular.ttf`, `Antonio-Bold.ttf` | Antonio (Vernon Adams and the Antonio Project Authors) | SIL Open Font License 1.1, `Antonio-OFL.txt` |
| `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf` | Noto Sans (the Noto Project Authors) | SIL Open Font License 1.1, `NotoSans-OFL.txt` |

The Antonio files are static weight-400 and weight-700 instances of the
variable `Antonio[wght].ttf` from github.com/google/fonts (`ofl/antonio`),
cut with fontTools' `varLib.instancer`, because Emerge registers one file
per weight. Antonio declares no Reserved Font Name.
